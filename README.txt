DIGITAL DOCUMENT MANAGEMENT SYSTEM - MINI PROJECT

CONTENTS
- server.js: Node.js/Express backend and API routes
- public/index.html: user interface
- public/style.css: page styling
- public/app.js: upload, search, download and delete interactions
- package.json: dependencies and start command
- uploads/: uploaded documents are stored here at runtime
- documents.json: metadata file is created automatically at runtime

HOW TO RUN (Node.js 18+ recommended)
1. Extract this ZIP file.
2. Open a terminal inside the extracted digital-document-management folder.
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000 in your web browser.
6. Upload a small PDF, DOC, DOCX, TXT, PNG or JPG file (maximum 5 MB).

IMPORTANT
This is an educational local demo. It does not include user login or access controls.
Do not use it for confidential documents or expose it publicly without security review,
authentication, authorization, stronger file validation, malware scanning and backups.
